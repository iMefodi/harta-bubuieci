# WebGIS Bubuieci

Portal WebGIS al satului Bubuieci (mun. Chișinău), realizat în cadrul cursului
PBL *Aplicații WebGIS (Open Source)*, Universitatea Tehnică a Moldovei.

**🌐 Portal:** https://imefodi.github.io/harta-bubuieci/
**🗺 Harta Leaflet (ecran complet):** https://imefodi.github.io/harta-bubuieci/harta/
**☁ Harta QGIS Cloud:** https://qgiscloud.com/Eduard_Iftodii/bubuieci_webgis/

## Structură

| Cale | Conținut |
|---|---|
| `index.html`, `assets/` | portalul: povestea vizuală, hărți interactive, hărți PNG, jurnalul lucrărilor |
| `harta/` | harta interactivă exportată din QGIS cu qgis2web (Leaflet) |
| `assets/harti/` | hărțile tematice A4, 200 dpi |
